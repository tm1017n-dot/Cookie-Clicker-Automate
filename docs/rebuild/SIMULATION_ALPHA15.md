# alpha.15 継続シミュレーションによる戦略評価

対象コミット: `51c2ffd64a6ca6f8a0bf0069f9955596cf195023`。配布コード・設定は変更していない。

## 方法

`node scripts/simulate-strategies.mjs` で再実行できる。[全入力・結果・購入履歴](simulation/alpha15-results.json)を保存した。処理時間は端末・JIT状態で変わるため再現性の対象外。

- 3つの設計ケース（開始時100クリック、遠方Tier、投資順）と、固定seed 1〜8の8ケース。
- 同一ケースでは初期資金・収益・施設・効果・クリック速度・Buffを一致させる。
- 15分×11ケース×5戦略の55試行。加えて3ケース×3戦略を60分まで延長する9試行、購入順だけを調べる3試行。合計67試行、56,400判断周期、仮想時間23時間30分。
- 1.5秒周期に最大1件を購入。待機中も収益とBuff終了を計算。終了時刻ちょうどには購入しない。
- 手持ち資金、累計生産（初期資金を除く）、クリック込み生産力、アップグレード到達時刻、閾値到達時刻を別々に記録する。施設の売却価値を資産へ加算しない。

比較戦略:

| 戦略 | 変更点 |
| --- | --- |
| current | alpha.15そのまま |
| fixed-horizon | 評価期間のみ60/300/900秒に固定。探索・予約は維持 |
| no-reservation | 毎周期予約を破棄して再評価 |
| greedy | 待ち時間＋価格÷増産量が最小の候補へ貯蓄・購入。解禁先読みなし |
| growth-weights | 評価重みを0.20/0.35/0.45から0.05/0.15/0.80へ変更 |

合成経済であり、実ゲームの長時間セーブ再生ではない。経済推移とPlannerは同じ純粋モデルを使うため、ゲーム効果式そのものの正しさを独立に検証するものではない。自然Golden Cookie、ミニゲーム、転生、測定遅延、未知効果は対象外。seedケースも同系統の3施設・Tier構成であり、全進行段階への一般化はできない。60分ケースと購入順プローブは初回結果を見て選んだ追加検証で、未使用データによる検証ではない。ブラウザ操作は行っていない。

## 1. 優先度が最も高い改善: 施設を先に増やす経路

investment-orderケースは資金100、受動収益10、施設1の単価100・生産10、施設2の単価1000・生産100。強化は価格1000の施設1倍率3倍、価格2000の施設半額、施設1を25個必要とする価格5000の倍率5倍。

| 項目 | 現行 | 最初に施設1を計6個揃え、現行へ戻す実験 |
| --- | ---: | ---: |
| 倍率3倍の購入 | 51秒 | 36秒 |
| 割引の購入 | 73.5秒 | 46.5秒 |
| 最終目標の購入 | 108秒 | 78秒 |
| 15分間の累計生産 | 8,925,195 | 9,310,380 |
| 15分後の手持ち資金 | 6,873,526 | 7,142,060 |
| 15分後の生産力 | 12,760/秒 | 12,860/秒 |

目標到達は27.8%短縮、累計生産は4.3%増加。施設数2個・4個までを先に揃えるプローブでも82.5秒で目標へ到達した。

これはケース専用の反実仮想実験で、固定購入順を製品へ入れる提案ではない。現行の直接経路と強化先行経路だけでは、途中の複数施設購入による加速を見落とせることを示す。少数の施設購入→強化、別施設への投資→目標復帰、複数強化の組合せを探索予算内で比較する改善が最優先。

## 2. 成長目的と手持ち資金目的を区別する

長期重視の重み実験は15分の全11ケースで累計生産を8.5〜18.7%、終了時生産力を9.9〜27.1%増やした。ただし手持ち資金は36.2〜98.2%減少した。全指標で優れているわけではなく、投資を増やした代償がある。

seed-2では生産力20,000/秒への初回到達が457.5秒→267秒、seed-8では802.5秒→420秒となった。Buff付きケースの初回到達は一時倍率を含むため、恒常生産力の達成とは扱わない。

60分追試の累計生産:

| ケース | 現行 | 長期重視 |
| --- | ---: | ---: |
| investment-order | 47,654,895 | 55,186,320 |
| seed-4 | 67,571,728 | 81,910,362 |
| seed-6 | 86,028,873 | 101,708,713 |

約15.8〜21.2%の増加は継続したが、手持ち資金は減少する。重みだけをこの試行へ合わせて採用せず、目標到達時間・継続投資の価値・必要な流動性を評価する設計を検討する。GC報酬やコンボを含む別データで再検証する必要がある。

## 3. 実験で支持されなかった変更

**評価期間を900秒へ固定:** 全11ケースで累計生産が5.4〜21.7%減少した。以前の「評価期間の延長を抑える」という提案は、単純な固定上限としては採用すべきでない。この実験は固定期間化を一括で変更しており、短期・中期だけを維持する設計等の効果は未検証。

**予約を全面廃止:** 3ケースは同じ、8ケースで累計生産が0.6〜20.1%減少した。seed-4では手持ち資金と生産力も低下した。予約は維持し、目標へ至る経路の見直しを改善するほうが妥当。

単純な回収時間戦略は全11ケースで生産量・生産力が現行を上回ったが、手持ち資金は82.0〜99.2%減った。また、割引は単体増産がないため買わない。これをそのまま置き換え案とはしない。

## 次の検証

1. 施設先行を含む複数経路を試作し、この購入順ケースと未使用のケースで目標到達を比較する。
2. 生産力の残存価値と流動性の必要額を分離し、予約・待機を含めて比較する。
3. GCやBuffの同一イベント系列、複数の進行段階の実セーブ入力を追加する。今回未評価の資金保護戦略を、この結果だけで断定しない。

シミュレーターには再実行の一致、入力不変、購入間隔、資金保存則の試験を追加した。既存テストを含め161件が合格。
