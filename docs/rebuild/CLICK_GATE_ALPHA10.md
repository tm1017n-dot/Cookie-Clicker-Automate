# alpha.10 100回/秒クリック境界の安定化

作成日: 2026-09-25。alpha.9の実画面報告を受けた修正。

## 症状と原因

alpha.9の短時間遅延補償により実クリックは約40回/秒から約50回/秒へ増えたが、目標100回/秒には達しなかった。Game 2.058の通常クリック処理は、前回クリックから20ms未満の呼び出しを拒否する。alpha.9以前のアダプターは100回/秒設定時に前回時刻をちょうど20ms前へ調整していたため、実ブラウザの時計取得境界では同じバッチの後続クリックが拒否される余地があった。

## 変更

- 100回/秒設定時の通常クリック呼び出しに、公式境界20msへ5msの余裕を加える。
- Cookieは直接加算せず、補完分も一回ずつGameの通常クリック処理を呼ぶ。
- 呼び出し前後のcookieClicksを比較し、成功したクリックだけを実測へ加える。
- UIに「要求回数」を追加する。要求が約100・実クリックが低い場合はゲーム側拒否、両方が低い場合はタイマー停止・メインスレッド遅延と区別できる。
- セーブ変更時にも要求・成功履歴と遅延枠をリセットする。

## 検証

自動試験137件、配布ビルド、全JavaScript構文、純粋層検査に合格。20msちょうどでは拒否する境界モックへ同一処理内で連続2回要求し、両方が成功することを確認した。25msタイマーの99〜100回/秒、最大5回、長時間停止後の大量連打防止、拒否クリック非計上の試験も維持する。

ブラウザでの実測はユーザー指示に従い実施していない。更新後はUIの「要求」と「実クリック」を別々に確認できる。バックグラウンドタブで100msを超えて停止した時間は安全のため補完しない。
