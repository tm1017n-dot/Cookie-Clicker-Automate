# alpha.14 長期目標途中の強化Upgrade

作成日: 2026-09-25。alpha.13の長期目標経路へ、任意の先行投資を加える拡張。

## 目的

TierやKitten等へ直接進む経路だけでなく、途中で施設強化または価格割引Upgradeを購入したほうが、将来購入する施設・目標Upgradeを含めて有利になる場合を評価する。

## 経路生成

各長期目標について次を比較する。

1. 解禁条件へ直接進む経路。
2. 目標経路で購入する施設を強化するUpgradeを先に購入する経路。
3. 施設価格またはUpgrade価格を下げるUpgradeを先に購入する経路。
4. 目標施設と関係するSynergyを先に購入する経路。

先行Upgradeの効果を状態へ適用してから、施設価格、施設単価、Synergy、実績、Milk、目標Upgrade価格を再計算する。そのため、現在の施設だけでなく、後から購入する施設にも倍率が引き継がれる。割引は割引後の未丸め価格を使える候補に適用する。

候補は目標との関連度、待ち時間、回収時間、価格で並べ、1目標あたり最大6件、全体で最大24経路に制限する。全長期経路の購入計算予算は従来どおり1024行動。PlannerはWeb Worker内で実行する。

先行投資経路は、直接経路より目標到達時間を1フレーム超短縮する場合だけ比較対象へ加える。施設を強化しても目標到達が速くならない案を、将来価値だけを理由に遠い目標へ結び付けない。

一般的なCpS増加Upgradeは従来の短期探索と、予約目標を早める1手比較で扱う。長期目標と無関係な高収益Upgradeを目標経路へ結び付けると、不要な長期予約が作られるため、今回の追加経路は施設固有の倍率、Synergy、価格割引に限定する。

## 選択と実行

- 未予約時は、直接経路と先行投資経路を同じ複数期間の資産価値で比較する。
- 予約中は、目標到達時間が最短になる経路を採用する。
- 先行投資を採用しても、実行するのは先頭のUpgrade 1件だけである。未予約時はまずこのUpgradeを予約し、遠い目標へ早期に拘束しない。
- 購入後はGameを再取得し、元の長期目標を含めて全経路を再計画する。既に長期目標を予約中なら、その予約を維持したまま到達時間を短縮する先行投資を許可する。
- 先行投資経路は診断の`unlockPaths`へ`variant: investment`と`investmentId`を保存する。

## 検証

自動試験149件、配布ビルド、全JavaScript構文、純粋層検査に合格した。

- 将来10施設を購入する目標で、対象施設を100倍にするUpgradeを先に選択する。
- 施設と目標Upgradeの双方を半額にするUpgradeで、総費用と到達時間が短縮する。
- 無関係な高収益Upgradeへ長期目標の予約を付けない。
- 既存の予約救済、短期探索、旧診断再生を維持する。

ユーザー指示に従いブラウザ検証は実施していない。1本の長期経路へ自動挿入する任意Upgradeは現段階で1件であり、複数の任意Upgradeを組み合わせる経路は今後の拡張対象となる。
