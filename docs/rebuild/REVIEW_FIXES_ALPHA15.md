# alpha.15 レビュー指摘の修正

対象: alpha.14 / 7c224b9。ブラウザ検証はユーザー指示により実施しない。

## 測定の進捗

魔力は現在対応する施設・Upgrade購入の価格・生産に影響しないため、測定キャッシュと購入直前の署名から除外する。施設数・所有Upgrade・Buff等の変更では従来どおり測定結果を破棄する。一方、最後に測定した順序は保持し、未測定または長く測定していない候補から処理する。予約対象を先に測定し、1周期最大4回のCalculateGains制限を維持する。セーブ識別情報の変更では進捗も初期化する。古い状態の効果量は流用しない。

## 予約の復帰

予約対象が消失・購入対象外になった場合は解除し、通常比較へ戻す。効果や経路の一時的な評価不能はswitchConfirmations（既定3）周期確認し、復帰しなければ解除する。正常化した場合は連続回数をリセットする。解除理由・回数をreservationRecoveryに記録する。資金待ち時間による解除ではない。未確定の購入、購入可能な予約対象の排他性、失敗後の同周期Fallback禁止は維持する。

## 購入間隔

仮想購入後にnextPurchaseAtを設定し、通常探索・解禁経路・先行投資・予約救済の資金ETAで次回購入までの時間を含める。その間の収益、Buff終了、イベントも積分する。先頭の購入は現在可能なら時刻0でよいが、以後はpurchaseIntervalMs（既定1500ms）以上空ける。資金が十分な41行動の経路は最短60秒となる。

これは実行間隔の下限モデルである。タイマーの位相による端数待ち、Worker計算、状態取得や保存の遅延までは含まず、実機の到達時間を保証しない。

## 長期目標

経路が既知で純増収益が正なら、研究・予約の有無によらず共通の長期評価期間を4×（到達時間＋経路費用÷純増収益）まで延長する。全候補を同じ期間で比較する。短期投資の存在だけで未予約Tier等が900秒の外へ除外される問題を解消する。探索予算と先行投資候補数は維持する。

期間延長はヒューリスティックであり、大域最適性は保証しない。非常に遠い目標が共通期間を長くする場合の戦略品質は、今後の長時間ベンチマーク対象となる。

## 検証と互換性

自動試験159件、配布ビルド、構文・純粋層検査に合格。実ブラウザ・長時間攻略の速度比較は未実施。

魔力回復中の測定完了と購入成功、施設変動下の測定順、予約消失と一時復帰、41行動の所要時間と待機収益、短期探索の購入間隔、長期目標の比較参加を回帰試験化した。さらに25状態で時間イベント・クリックを含む各探索ノードを経路全体の再計算と照合する。

alpha.14の純粋層をscripts/legacy/alpha14へ保存し、旧診断は旧エンジンで再生する。過去の性能最適化に関する判断一致テストは該当保存版同士の比較として維持する。availability待機テストの2購入完了時刻は、購入間隔の修正により10秒から11.5秒へ変更した。序盤購入等の既存判断fixtureは変更していない。
