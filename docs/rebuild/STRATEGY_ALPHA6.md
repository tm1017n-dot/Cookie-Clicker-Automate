# alpha.6 相乗効果・自然GC・研究経路

## 実装契約

公式Web 2.058の取得済みmain.js（出典・ハッシュはSTRATEGY.md）を一次資料とし、日本語Wikiの施設、ミルク、GC、研究の攻略情報を対応付ける。固定購入順は追加しない。

1. **動的生産**：保有Synergyの施設数依存倍率、Grandma系列、Kittenのミルク倍率を基準状態からの比率として再計算する。施設Tier実績は同一実績を一度だけ数える。追加効果は実測差分と照合し、一致しない対象は単発測定へ戻す。未監査の実績や特殊倍率を推測しない。
2. **GC**：候補共通の固定seedによる少数シナリオで自然GCの待ち時間、効果抽選、Frenzy・Click frenzy・Building special・Luckyを予測する。Luckyの上限は受動CpSだけ。予測利益と下振れ評価は資産価値へ反映し、bank・購入可能性・資金ETAへは入れない。現在のGCタイマーは頻度強化購入で即座に半減せず、次回以降の間隔だけ変える。無限探索を避けるため予測期間・イベント数を固定予算で制限し、制限を診断へ明記する。
3. **研究**：BingoからUnderworld ovensまでの研究を、前提購入→研究時間→解禁→購入の経路として生成する。稼働中の残り時間も反映する。実行は通常の購入APIを一回呼び、研究コールバックは仮想実行しない。One mind以降はWrath・虫の戦略が未対応のため境界を明示し、この変更で自動進行しない。

GCは通常GC自動回収が有効で、Wrath・特殊召喚等の未対応条件がない場合に評価する。Cookie storm・chain等の未実装報酬はゼロ評価と明記する。少数サンプルは完全な期待値や攻略最適性の保証ではない。実績は施設メタデータから確定できる閾値を対象とする。

## 検証計画

相乗効果を保有した状態からの施設購入、Synergy取得、実績閾値の前後、複数Kittenの積、CpS連動クリック、GC収益を使えないETA、バフ重複・終了、GC頻度と現行タイマーの分離、研究時間と購入条件、入力不変性、旧版JSON再生を試験する。ブラウザ検証はユーザーの明示依頼時のみ。

## 計算範囲と診断

- 自然GCは既定8シナリオ、seed 713、60分・各64イベントまで。候補間で同じ乱数系列を使う。通常GCのフレームごとの出現確率を反転して待ち時間を生成する。シナリオの平均から下位10%標本との差の10%を差し引く。8標本での下位値は最小値であり、統計的な信頼区間ではない。
- 診断のgoldenModelにはseed、標本数、予算、リスク係数、各評価期間で何も購入しない場合のmean/lower/value/limited、未評価報酬を記録する。上限以後も確定生産の評価は続く。GC収益の打切りによって長期比較が保守的になる場合がある。
- GC回収を無効にしている場合、Wrath、GCが既に出現中、Dragonflight等の特殊条件ではGC予測を外し、理由を表示する。通常購入の評価は継続する（既存の未対応ゲーム状態による停止条件は別）。
- 施設実績からKitten解禁へ至る経路は、次の実績までの追加時間を比較する予算付き貪欲探索。24購入・共有256試行の制限があり、大域的最適解ではない。Cursor固有実績や生産総量等、tieredAchievsで確定できない実績は今回の先読みに含めない。
- 研究はBingo、Specialized chocolate chips、Designer cocoa beans、Ritual rolling pins、Underworld ovensが対象。研究コールバックの内容を照合し、未知の副作用がある候補を許可しない。Underworld ovens購入でゲーム内の次研究は始まるが、One mindを自動購入しない。
- 既存の測定限定候補との一手比較、予約対象の排他的購入、クリック実測、固定手順を使わない方針を維持する。alpha.5エンジンを保存し、旧診断をその版で再生する。

## 検証結果（2026-09-24）

自動試験125件、配布ビルド、構文・純粋層検査を実施。追加ケースは合成状態とGameモックであり、新たな実セーブの攻略効果を実証したものではない。ブラウザ確認はユーザー指示により実施しない。

Node 24.19.0でのPlanner単体の合成ベンチマークでは、25候補の既存ケースで中央値約4ms、自然GCを含むケースで約8ms。Game観測、UI描画、ブラウザ全体の負荷は含まない。固定予算と結果をscripts/benchmark.mjsで再測定できる。
